# Jornada Python — aplicações no agro

Repositório de estudos de **Python 3**, organizado por tópicos e pequenos exercícios relacionados ao agronegócio. O objetivo é documentar minha evolução, do básico até projetos de automação e análise de dados agrícolas.

## Conteúdos

| Pasta | Tema |
|---|---|
| `01_fundamentos/` | Variáveis e `print()` |
| `02_strings/` | Texto, métodos e concatenação |
| `03_numeros/` | Inteiros, decimais e operações |
| `04_listas/` | Índices, inclusão, remoção, ordenação |
| `05_desafios/` | Exercícios resolvidos e desafio para praticar |
| `docs/` | Diário de aprendizado e próximos passos |

## Como executar

1. Instale uma versão recente do Python 3.
2. Abra esta pasta no VS Code.
3. No terminal, execute, por exemplo:

```bash
python 04_listas/02_adicionar_remover.py
```

Se o comando `python` não funcionar, tente `python3` (macOS/Linux) ou `py` (Windows).

Não é necessário instalar dependências externas.

## Aprendizado e autoria

Os arquivos são **exemplos didáticos reescritos e organizados** com base em conceitos estudados no livro *Curso Intensivo de Python*, de Eric Matthes, e nas sessões de revisão. Não representam projetos de produção. A pasta `05_desafios/` diferencia soluções de referência de um exercício para resolver de forma independente.

Acompanhe o que já pratiquei em [docs/PROGRESSO.md](docs/PROGRESSO.md).
